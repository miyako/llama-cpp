Before you begin

A small engine. A broad reach.

The component bundles native server executables for macOS and Windows. Choose a GGUF model that fits your hardware, memory, and use case; model weights are downloaded separately.

Platform and model requirements
You bringWhat to know
A MacmacOS 14+ on Apple Silicon or Intel. The universal build includes embedded Metal shaders.
Or a Windows machineSeparate native x64 and ARM64 executables. These builds use the CPU backend, not CUDA or Vulkan.
A compatible GGUF modelCheck its license, RAM requirements, chat template, and supported tasks. Vision also needs the model's compatible multimodal projector.
4D 20+ for integrationInstall the component and its dependencies. Direct HTTP use does not require 4D.
Local inference, not a hosted service.

After downloading the server and model assets, inference runs on your machine. Keep the listener on 127.0.0.1 unless you have deliberately secured network access.

From download to conversation

Your first local request.

Download the component from GitHub Releases and locate the executable under Resources/bin/macOS, Resources/bin/Windows, or Resources/bin/WindowsARM. Download a compatible chat GGUF model separately.

01

Start the engine

Shell / macOS

Open a terminal in the executable's directory. Replace the model path below with your downloaded file. On Windows, use .\llama-server.exe with the same arguments on one line.

{% highlight shell %} ./llama-server \ --model "/path/to/chat-model.gguf" \ --alias local-model \ --host 127.0.0.1 \ --port 8080 {% endhighlight %}
02

Wait until it's ready

Shell

Leave the server running. In another terminal, check health until you receive HTTP 200. Starting the process does not mean the model has finished loading.

{% highlight shell %} curl --fail http://127.0.0.1:8080/health {% endhighlight %}
03

Start a conversation

Shell / macOS
{% highlight shell %} curl http://127.0.0.1:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "local-model", "messages": [{"role": "user", "content": "Hello from 4D."}], "max_tokens": 128, "stream": false }' {% endhighlight %}

The multiline curl examples use POSIX shell quoting; in Windows PowerShell, use curl.exe and adapt the quoting or send the JSON from a file. For streaming responses, use curl -N and set "stream": true.

Connect with tools you know

A familiar API. A local address.

Point AI Kit's OpenAI client at your local server. Run an embedding model with --embeddings and the pooling mode required by that model to use the embeddings endpoint.

{% highlight 4d %} var $AIClient : cs.AIKit.OpenAI $AIClient:=cs.AIKit.OpenAI.new() $AIClient.baseURL:="http://127.0.0.1:8080/v1" {% endhighlight %}
AI Kit endpoint compatibility

Images, moderations, files/v1/images/generations, /v1/moderations, /v1/filesNot supported by this integration

Vision and OCR depend on the loaded model. Pass images as data URIs in chat requests rather than uploading them to a files endpoint.
